CHANGELOG
=========

1.0.1
-----
- SPECTATE button in the SERVERS panel: joins the spectator/director URL on the clipboard
  (<ip>:<port>?SpectatorOnly=1&AuthToken=...). Ini key SpectateUrl= is the fallback.

1.0.0
-----
First public release.
- Community backend (sos.joltora.com:7781) with no game config edits.
- SERVERS button and live server list; join a server in one click, automatic PLAY.
- Vote to start a match from the list.
- REPORT panel: report a player with a reason and an optional clip link.
- Relaunch announcement instead of the old shutdown notice (text and colours editable).
- "OG SOS Revival" build label.
- Unreleased Ronin outfit parts and one beard selectable (UnlockUnreleasedCosmetics).
- Optional borderless window, console variables ([Cvars] in the ini), text options.
- Signed self-update (AutoUpdate=1): stable loader plus replaceable core, Ed25519
  signature check, downgrade protection, rollback to the previous version.
- Steam DLC unlock is OFF by default in this release (UnlockDlcCosmetics=0).
